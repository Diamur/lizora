# Lizora

Персональный образовательный веб-ресурс Лизы.
Платформа для обучения с интегрированными видеоуроками, теоретическими материалами, квестами и программированием.

## Развёртывание локально

### 1. Установите зависимости

```bash
npm install
```

### 2. Настройте переменные окружения

Скопируйте шаблон и отредактируйте `.env.local`:

```bash
cp .env.example .env.local
```

Для генерации `ADMIN_PASSWORD_HASH` выполните:

```bash
node -e "const b=require('bcryptjs'); b.hash('ВАШ_ПАРОЛЬ',10).then(h=>console.log(h))"
```

> **Важно:** bcrypt-хеши содержат символы `$`. В `.env.local` их необходимо экранировать
> обратным слешем, иначе `dotenv-expand` интерпретирует их как переменные окружения:
>
> ```env
> # Неправильно — $ интерпретируется как переменная:
> ADMIN_PASSWORD_HASH=$2b$10$abc...
>
> # Правильно — каждый $ экранируется \$:
> ADMIN_PASSWORD_HASH=\$2b\$10\$abc...
> ```

### 3. Установите ffmpeg

`ffmpeg` требуется для автоматической конвертации `.wmv` видео в MP4.
Скачайте с [ffmpeg.org](https://ffmpeg.org/download.html) и добавьте в `PATH`.

Проверьте:

```bash
ffmpeg -version
```

### 4. Запустите сервер разработки

```bash
npm run dev
```

### 5. Откройте в браузере

- Публичная часть: <http://localhost:3000>
- Панель администратора: <http://localhost:3000/admin>
